GALAXIA HOT WHEELS — PÁGINA LISTA PARA PUBLICAR

ARCHIVOS:
- index.html
- styles.css
- script.js
- music.mp3 (opcional, no incluido)

PUBLICAR GRATIS CON GITHUB PAGES:
1. Entra a https://github.com y crea un repositorio nuevo, por ejemplo: galaxia-hotwheels
2. Sube index.html, styles.css y script.js.
3. Ve a Settings > Pages.
4. En "Build and deployment", selecciona "Deploy from a branch".
5. Branch: main / root.
6. Guarda.
7. GitHub te dará un enlace parecido a:
   https://TU-USUARIO.github.io/galaxia-hotwheels/

PUBLICAR GRATIS CON NETLIFY:
1. Entra a https://app.netlify.com/drop
2. Arrastra la carpeta completa.
3. Netlify genera un link público automáticamente.

MÚSICA:
Pon tu canción en formato MP3 dentro de la misma carpeta con el nombre exacto:
music.mp3

PERSONALIZAR:
Edita index.html y cambia los mensajes que quieras.
